# Results

## 1. Numerical validation and research findings

The tracked results here concern the baseline mathematical validation configuration. They are not market observations. The [paper's numerical supplement](../paper/numerical_results.md) separately records the completed conditional research findings, and the [CPU supplement](../paper/cpu_timings.md) supplies the workload measurements behind Table 9.

The [public reproduction command](../docs/reproducing_paper.md) writes each new run to a fresh, ignored directory under `data/private/reproduction`. It leaves the retained results unchanged and does not read or export restricted financial data. Exact financial replay has the separate input requirements documented in the [replication guide](../replication/README.md).
