# Numerical specifications

The [baseline specification](benchmark.json) contains stipulated inputs for mathematical validation. The [historical event calendar](us_event_calendar_2026-09-16.json) contains attributed holiday and session information, with future assumptions labelled explicitly. It is retained as the original dated test resource and is not a claim that every future convention has been verified.

The public conditional-study interface has its own [stipulated specification](../replication/configs/stipulated_fixture.json) and [input schema](../replication/input.schema.json). Original financial configurations and provider responses remain private. A new authorised financial specification defines a new experiment; it cannot replace the original input archive in an exact-replay claim.
